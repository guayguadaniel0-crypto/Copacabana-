# Copacabana - Página Web Publicitaria

## Descripción del Proyecto
Página web publicitaria completamente funcional sobre Copacabana, Bolivia - "La Perla del Lago Titicaca". Diseñada con HTML, CSS y JavaScript vanilla (sin frameworks ni Node.js).

## Características Principales

### Secciones Completas
1. **Hero** - Página de inicio con efecto parallax y fondo del Lago Titicaca
2. **Historia** - Información sobre los orígenes de Copacabana
3. **Basílica** - Detalles de la Basílica de Nuestra Señora de Copacabana
4. **Lago Titicaca** - Características del lago navegable más alto del mundo
5. **Isla del Sol** - Información sobre el sitio sagrado inca
6. **Gastronomía** - Platos típicos (Trucha, Pejerrey, Api, Chupe de Pescado)
7. **Festividades** - Timeline visual con celebraciones principales
8. **Galería** - Colección de 6 imágenes de la región

### Efectos y Animaciones
- ✨ Efectos parallax en secciones hero, basílica e isla
- 🎭 Animaciones al scroll usando Intersection Observer API
- 🌈 Colores vibrantes inspirados en Bolivia (azules del lago, naranjas de atardeceres, colores andinos)
- 💫 Partículas flotantes animadas en el hero
- 🔄 Transiciones suaves en tarjetas, galería y elementos interactivos
- 📱 Diseño completamente responsivo para móviles y tablets

### Navegación
- Menú sticky con efecto de scroll al desplazarse
- Navegación suave entre secciones con scroll automático
- Indicador de scroll animado en la página principal
- Hover effects en todos los enlaces y botones

## Tecnologías Utilizadas
- HTML5 semántico
- CSS3 (Grid, Flexbox, Animaciones, Gradientes)
- JavaScript Vanilla (Intersection Observer, Event Listeners)
- Python HTTP Server para desarrollo

## Servidor de Desarrollo
El proyecto usa un servidor HTTP simple de Python en el puerto 5000:
```bash
python -m http.server 5000
```
